# Entrelinhas

Portal fictício para um trabalho escolar de português sobre *A metamorfose*, de Franz Kafka.

## Executar

Requer Node.js 20.19+ ou 22.12+.

```bash
npm install
npm run dev
```

Abra o endereço mostrado pelo Vite. Para gerar uma versão de produção, use `npm run build`; para servi-la localmente, use `npm run preview`.

Não há cadastro, backend, compra, áudio externo ou serviço pago. Enquete e comentários ficam no armazenamento local do navegador. As imagens são recursos SVG incluídos em `public/images`.
